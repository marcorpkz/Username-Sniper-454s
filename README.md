# Username Sniper by 454s

A modern Roblox username availability checker with a custom dark interface, real-time results, and a clean dashboard.

## Features

- **Username Checker:** Checks whether randomly generated usernames are available on Roblox.
- **Real-Time Results:** Displays available usernames directly in the dashboard.
- **Dashboard:** Custom dark interface with red accents and live statistics.
- **Pause and Resume:** Control the search whenever you want.
- **Copy Results:** Copy selected usernames or all available usernames.
- **Save Results:** Automatically saves available usernames to `validos.txt`.
- **Clear Results:** Clear the results displayed in the application.

## Built With

- Python
- CustomTkinter
- Requests
- Pillow

## Installation

1. Clone this repository:

```bash
git clone https://github.com/marcorpkz/Username-Sniper-454s.git
```

2. Open the project folder:

```bash
cd Username-Sniper-454s
```

3. Install the dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python sniper_dashboard.py
```

## Disclaimer

This project is intended for educational purposes. It uses Roblox's public username validation endpoint to check username availability.

Please use responsibly and respect Roblox's API limits and terms of service.
